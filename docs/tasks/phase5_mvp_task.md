## P0 — до 22:45

### P0.1 Режим відтворення (demo) — 35 хв

Рецензент не має Telegram-сесії, тому без цього продукт у нього не запуститься.

- `airalert serve --replay 2026-10-05T15:00:00Z`:
  - джерела — **закомічені** `data/processed/alerts.parquet` (+ `drone_mentions.parquet`, якщо потрібно), обрізані **по known_at ≤ replay-годинник**; годинник API стартує з `--replay` і йде вперед у реальному темпі (є вже інʼєкція `clock` в `create_app` — використай її);
  - модель: `airalert model-fit --until <ts> --out data/work/replay/` — ансамбль, навчений **лише на даних до ts** (без витоку); якщо швидше — взяти walk-forward модель доби з `model_eval`, але з тим самим правилом;
  - `/api/state` повертає `"mode": "replay", "replay_at": …`; фронтенд показує непомітну плашку «Режим відтворення: станом на 05.10, 18:00» (i18n, `--muted`).
- Обери за замовчуванням момент **спокою з цікавою кривою** (є дрони поруч / нещодавня тривога) з тестового періоду; також другий пресет — **під час тривоги**. `make demo` і `make demo-alert`.
- Тест: у replay жоден рядок з `known_at > clock` не потрапляє в state/ознаки (обрізати і порівняти).


## P1 — після P0 (до сабміту, якщо встигаєш; інакше одразу після)

- **Proxmox-готовність** `docs/DEPLOY.md`:
  - рекомендація: **VM** (Debian 12/Ubuntu 24.04) з Docker; якщо LXC — лише з `nesting=1,keyctl=1` і попередженням про overlayfs; ресурси: 2 vCPU, 2–4 ГБ RAM, 10 ГБ диска;
  - образ збирається **на сервері** (amd64), без закріпленої платформи; перевір `docker compose build` на `linux/amd64` через buildx локально;
  - що копіювати вручну: `.env`, файл сесії (600, поза репо), опційно `data/live` для збереження історії;
  - HTTPS для геолокації: Tailscale Funnel на хості (`tailscale funnel 8000`) або Cloudflare Tunnel; **порти на роутері не відкривати**; API лишається на `127.0.0.1:8000`;
  - бекапи: `make snapshot` у cron щоночі, ротація 7 днів;
  - оновлення: `make deploy` → `make up` (дані не перезаписуються);
  - моніторинг: `/api/health` + `docker compose ps`.
- Бюджет фронтенду: власні JS+CSS зараз ~64 КБ при цілі 60 — мініфікація без збірки не потрібна; просто прибери мертвий код/дублікати або онови ціль у README з поясненням.
